Compatibility Privacy

This public community site is separate from UIF's private application repository.

Reading Reports

The site has no analytics, cookies or advertising scripts. GitHub Pages receives ordinary web requests, including connection information such as your IP address. See GitHub's privacy statement.

Importing a File

File previews and schema checks happen locally in your browser. Selecting a file does not upload it. Only choose a UIF compatibility report, never a support bundle. No ROM, runtime, save, key, ticket or binary upload is needed.

Submitting a Report

You must review the preview and explicitly open and submit GitHub's form. Your GitHub identity, report and any comments are public. Game names, base names and notes can contain personal information: remove it before submitting. Maintainers check reports before adding them to the public dataset. Review does not mean independent reproduction.

Update Checks

The Desktop app can optionally fetch a small stable-version JSON file from this site on launch. It sends no compatibility report, pairing code, console address or installed-version identifier. The web host still sees ordinary request metadata. No update is downloaded or installed automatically.

Corrections and Removal

Open an issue in the public community repository to request a correction or removal. Git history and third-party copies may retain earlier public data. Do not publish sensitive information in the first place.
